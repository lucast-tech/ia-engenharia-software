# IA VS Engenharia de Software

Este repositório discute a diferença entre geração de código por inteligência artificial e engenharia de software.

## Contexto

Ferramentas de IA permitem gerar aplicações completas rapidamente a partir de linguagem natural. Isso reduz a barreira de entrada para desenvolvimento, mas não garante qualidade técnica.

## Problema

Existe uma confusão crescente entre:

- gerar código com IA  
- construir software com engenharia real  

Código funcional não significa sistema seguro, escalável ou bem projetado.
