# IA vs Engenharia de Software

Este repositório foi criado para discutir a diferença entre geração de código por inteligência artificial e engenharia de software.

## Conteúdo

- Issue com discussão técnica sobre o tema
- Exemplo de código demonstrando risco de segurança em sistemas simples

## Objetivo

Mostrar que código funcional não garante software seguro, escalável ou bem projetado.
