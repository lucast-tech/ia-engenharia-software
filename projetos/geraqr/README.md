# GeraQR

Gerador de QR Codes simples e rápido, sem anúncios. Tudo acontece no navegador: o texto digitado não é enviado para nenhum servidor.

## Funcionalidades
- Gera QR Code a partir de texto, link ou contato (até 1500 caracteres)
- Copiar a imagem ou baixar em PNG
- Tema claro/escuro (segue o sistema ou o botão)

## Como usar
Use online em https://geraqr-lt.netlify.app/ ou abra o `index.html` no navegador. Não precisa instalar nada.

## Tecnologias
HTML, CSS e JavaScript puro, mais a biblioteca [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) carregada por CDN.
