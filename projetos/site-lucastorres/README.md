# Site Lucas Torres Tecnologia

Arquivos do site [lucast.tech](https://www.lucast.tech) (meus sites de criança estão em [lucast.tech/infancia](https://www.lucast.tech/infancia)): página única (`index.html`) com início, sobre, certificações, aplicativos e contato.

| Arquivo | Para que serve |
|---|---|
| `index.html` | O site inteiro (HTML, CSS e JS na mesma página) |
| `logo.png` | Logo / ícone |
| `sitemap.xml` | Mapa do site para buscadores |
| `robots.txt` | Regras para robôs de busca |
| `llms.txt` | Resumo do site para IAs |
| `_redirects` | Regras de redirecionamento da hospedagem (Netlify) |
